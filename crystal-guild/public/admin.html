채널 자동 알림

  1. 디스코드에서 알림 받을 채널의 채널 편집 → 연동 → 웹후크 → 새 웹후크
  2. 웹후크 URL 복사를 눌러 아래에 붙여넣고 저장

디스코드로 로그인

  1. 디스코드 개발자 포털에서 New Application 만들기
  2. 왼쪽 OAuth2 메뉴에서 Client ID와 Client Secret(Reset Secret)을 복사해 아래에 입력
  3. 같은 화면 Redirects에 아래 주소를 그대로 추가하고 Save

디스코드로 처음 로그인하면 서버 닉네임으로 계정이 자동으로 만들어져요. 길드원 목록에 디스코드 표시가 붙습니다.
