길드원

닉네임로또권빠른 지급디스코드 ID가입최근 로그인

채널 자동 알림

  1. 디스코드에서 알림 받을 채널의 채널 편집 → 연동 → 웹후크 → 새 웹후크
  2. 웹후크 URL 복사를 눌러 아래에 붙여넣고 저장

디코로 글 보내기

사이트에는 올라가지 않고 디스코드 채널에만 보내져요.

디스코드 봇

채널 웹후크로는 개인 DM을 보낼 수 없어서, 개인 DM은 디스코드 봇으로 보냅니다.

  1. 디스코드 개발자 포털에서 앱을 고르거나 새로 만들기 (전에 만든 앱을 써도 돼요)
  2. 왼쪽 Bot 메뉴 → Reset Token → 나온 토큰을 복사해 아래에 붙여넣고 저장
  3. 봇 확인을 누르면 나오는 초대 링크로 봇을 길드 디스코드 서버에 초대

DM을 받으려면 길드원이 사이트에 디스코드 ID를 등록하고, 봇과 같은 서버에 있으면서 서버 멤버의 DM을 허용해 두어야 해요.

슬래시 명령어

디스코드에서 /사이트를 쓰면 사이트 링크를 보여줘요 (친 사람에게만 보임). (봇 토큰 먼저 저장)

  1. 개발자 포털 → 같은 앱 → General Information에서 Public Key를 복사해 아래에 저장
  2. 같은 화면 Interactions Endpoint URL에 아래 주소를 붙여넣고 Save
  3. 지금 등록 누르기 — 이 기기 인터넷으로 디스코드에 바로 등록해서, 사이트 서버가 디스코드에 막혀(오류 429) 있어도 돼요. 안 눌러도 사이트가 알아서 계속 시도해요.

봇 이름 옆이 '오프라인'으로 보여도 명령어는 정상 작동해요. (사이트가 켜져 있으면 언제든 응답)
