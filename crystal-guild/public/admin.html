운영자 로그인

응모 현황

추첨할 때 1등 당첨자가 있으면 공지사항에 "제N회 로또 1등 당첨자 발표" 글이 올라가요. 공지사항 메뉴에서 수정·삭제할 수 있어요.

카지노

블랙잭(딜러)과 블랙잭 1대1을 한 번에 열고 닫아요. 닫으면 길드 사이트에서 블랙잭 탭이 사라지고, 상대를 기다리던 1대1 방은 취소되어 건 로또권을 돌려줘요. 이미 진행 중인 판은 끝까지 할 수 있어요.

블랙잭 설정

배당: 승리 2배 · 블랙잭 2.5배(내림) · 무승부 반환 · 딜러는 17 이상에서 멈춤

블랙잭 오늘 현황

최근 판

8비트 레이드 설정

처치 보상은 그 보스에게 한 번이라도 도전한 길드원 모두에게 줘요. 0이면 보상 없음. 잘하는 사람이 한 판에 8만~10만쯤 피해를 넣어요.

데이터 백업

길드원(비밀번호는 암호화된 그대로)·로또권·회차·응모·공지·신청·프로필 사진·활동 기록을 파일 하나로 받아요. 봇 토큰·웹후크 같은 비밀 설정은 들어가지 않아요.

백업으로 복원

지금 사이트의 길드 데이터를 모두 지우고 백업 파일 내용으로 바꿔요. 다른 사이트로 옮길 때도 써요. 되돌릴 수 없으니 먼저 지금 데이터를 백업해 두세요.

쿠폰 만들기

선착순 인원 0 = 무제한. 사이트 쿠폰 채널에 올리면 길드원이 받기 버튼으로 받고, 올리지 않은 쿠폰은 코드를 아는 사람만 입력해서 받아요. 한 사람당 한 번만 받을 수 있어요.

디스코드 쿠폰 채널

쿠폰을 만들면 디스코드 쿠폰 채널에 코드가 카드로 올라가요. 쿠폰 채널의 채널 편집 → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사 후 붙여넣고 저장하세요.

디스코드 봇

채널 웹후크로는 개인 DM을 보낼 수 없어서, 개인 DM은 디스코드 봇으로 보냅니다.

  1. 디스코드 개발자 포털에서 앱을 고르거나 새로 만들기 (전에 만든 앱을 써도 돼요)
  2. 왼쪽 Bot 메뉴 → Reset Token → 나온 토큰을 복사해 아래에 붙여넣고 저장
  3. 봇 확인을 누르면 나오는 초대 링크로 봇을 길드 디스코드 서버에 초대

DM을 받으려면 길드원이 사이트에 디스코드 ID를 등록하고, 봇과 같은 서버에 있으면서 서버 멤버의 DM을 허용해 두어야 해요.

슬래시 명령어

디스코드에서 /사이트를 쓰면 사이트 링크를 보여줘요 (친 사람에게만 보임). (봇 토큰 먼저 저장)

  1. 개발자 포털 → 같은 앱 → General Information에서 Public Key를 복사해 아래에 저장
  2. 같은 화면 Interactions Endpoint URL에 아래 주소를 붙여넣고 Save
  3. 지금 등록 누르기 — 이 기기 인터넷으로 디스코드에 바로 등록해서, 사이트 서버가 디스코드에 막혀(오류 429) 있어도 돼요. 안 눌러도 사이트가 알아서 계속 시도해요.

봇 이름 옆이 '오프라인'으로 보여도 명령어는 정상 작동해요. (사이트가 켜져 있으면 언제든 응답)
