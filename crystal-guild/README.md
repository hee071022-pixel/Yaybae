# 💎 크리스탈 길드 로또

길드원 전용 로또 사이트입니다. **Netlify** 한 곳에서 화면 + 서버(Functions) + 저장소(Blobs)까지 모두 돌아가서 별도 DB가 필요 없습니다.

## 기능

메인 메뉴: **🏠 홈 · 📢 공지사항 · 🎰 이벤트(로또)** — 공지는 로그인 없이 볼 수 있고, 운영자가 운영실 **공지사항** 메뉴에서 작성·수정·고정·삭제합니다.

**길드원 (`/`)**
- 닉네임 + 비밀번호로 가입 / 로그인
- 보유 로또권과 지급·사용 내역 확인
- 1~45 중 6개 직접 고르기 또는 자동 — 로또권 1장 = 1줄, 한 번에 여러 줄 응모
- 추첨 결과 애니메이션, 내 번호 중 맞은 번호 강조, 등수 표시
- 지난 회차 당첨번호 / 당첨자 / 내 번호 결과

**운영자 (`/admin.html`)**
- 운영자 전용 로그인 (비밀번호는 Netlify 환경 변수)
- 로또권 지급·회수: 한 명(+1/+5/−1 빠른 버튼), 선택한 여러 명, 전체 길드원 / 사유 입력 가능
- 회차 열기 (1~5등 상품 설정) → 추첨하기 (당첨번호 6개 + 보너스 1개 무작위)
- 회차별 응모 현황과 당첨자 확인
- 길드원 비밀번호 초기화, 계정 삭제

**당첨 규칙** (한국 로또와 동일): 6개 1등 · 5개+보너스 2등 · 5개 3등 · 4개 4등 · 3개 5등

## Netlify 배포

1. Netlify → **Add new site → Import an existing project** → 이 GitHub 저장소 선택
2. 빌드 설정
   - **Base directory**: `crystal-guild`
   - Build command는 비워두기 (Publish / Functions 폴더는 `netlify.toml`에서 자동 인식)
3. **Site configuration → Environment variables** 에 추가

   | 이름 | 값 |
   |---|---|
   | `ADMIN_PASSWORD` | 운영자 비밀번호 (선택 — 없으면 처음 운영자 로그인 때 입력한 8자 이상 비밀번호가 저장되어 그 뒤로 사용됨) |
   | `ADMIN_ID` | 운영자 아이디 (선택, 기본 `admin`) |
   | `SESSION_SECRET` | 아무 긴 랜덤 문자열 (선택, 없으면 자동 생성) |

4. 배포 후 `https://<사이트>.netlify.app/admin.html` 에서 운영자 로그인

환경 변수를 바꾼 뒤에는 **Deploys → Trigger deploy** 로 다시 배포해야 적용됩니다.

## 응모 기간 (시간 설정)

회차를 열 때 **응모 기간**(예: 2026년 10월 4일 21:00 ~ 22:00)을 정할 수 있습니다. 진행 중에도 "응모 기간 바꾸기"로 수정할 수 있고, 비워두면 기간 제한이 없습니다.

- 시작 전에는 "응모 예정"과 시작까지 남은 시간, 진행 중에는 마감까지 남은 시간이 표시되고 그 시간에만 응모할 수 있습니다.
- "마감 시간에 자동 추첨"을 켜두면 마감되는 순간 자동으로 추첨합니다(예약 함수 `auto-draw`가 1분마다 확인, 사이트를 열어도 바로 처리). 디스코드 알림도 함께 나갑니다.
- 운영자는 언제든 "지금 추첨하기"로 직접 추첨할 수 있습니다.

## 디스코드 알림

운영실 → **디스코드 알림** 메뉴에서 설정합니다. 디스코드 채널 설정 → 연동 → 웹후크 → 새 웹후크 → URL 복사 → 운영실에 붙여넣고 저장하면, 공지 등록·회차 시작·추첨 결과(당첨번호·당첨자)가 채널에 올라갑니다. 항목별로 끄고 켤 수 있고, 환경 변수 `DISCORD_WEBHOOK_URL`로도 줄 수 있습니다(있으면 우선).

- **공지 알림**: 공지 쓸 때 "디스코드에도 알리기"로 공지마다 보낼지 고를 수 있고, 공지 알림에 @everyone / @here 멘션을 붙일 수 있습니다.
- **유저 멘션**: 길드원이 사이트(로또 이벤트 화면 아래 "디스코드 연결")에서 자기 디스코드 사용자 ID를 등록하거나 운영자가 길드원 목록에서 등록하면, 디코로 글 보낼 때 골라서 멘션하고 추첨 결과에 당첨자를 자동 멘션합니다. (ID 확인: 디스코드 설정 → 고급 → 개발자 모드 → 프로필 우클릭 → 사용자 ID 복사)
- **디코로 글 보내기**: 운영실에서 제목·내용을 써서 디스코드 채널에 바로 보냅니다(멘션 선택 가능, 사이트에는 안 올라감).

## 운영 순서 예시

1. 길드원들에게 사이트 주소를 알려주고 가입하게 함
2. 운영실에서 **1회 응모 시작** (상품 입력)
3. 출석·이벤트 보상으로 로또권 지급
4. 길드원들이 번호를 골라 응모
5. 정해진 시간에 **지금 추첨하기** → 결과가 모든 길드원 화면에 표시
6. **2회 응모 시작** (이전 상품 설정이 자동으로 채워짐)

## 개발

```bash
cd crystal-guild
npm install
npm test                    # API 전체 흐름 테스트 (로컬 Blobs 서버 사용)
node test/dev-server.mjs    # http://localhost:8888 , 운영자 비밀번호 admin1234
```

`netlify dev` 로도 실행할 수 있습니다.

## 구조

```
crystal-guild/
├─ netlify.toml
├─ netlify/functions/api.mjs   # /api/* — 로그인, 로또권, 응모, 추첨
├─ public/
│  ├─ index.html, app.js       # 길드원 화면
│  ├─ admin.html, admin.js     # 운영실
│  └─ common.js, style.css
└─ test/
```

데이터는 Netlify Blobs 저장소 `crystal-guild`에 저장되며, 비밀번호는 scrypt 해시로만 보관합니다.
